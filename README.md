## 📋 Короткий опис виконаних завдань

### 🟢 Рівень 4–6 балів
1. **Привітання користувача:** Отримання імені через `prompt` та виведення повідомлення за допомогою `alert` із використанням шаблонних рядків (\`${userName}\`).
2. **Розрахунок року народження:** Обчислення року народження на основі введеного віку (`currentYear - age`).
3. **Повне ім'я:** Формування повного імені через конкатенацію (оператор `+`) та шаблонні рядки (вивід у `console.log`).

### 🟡 Рівень 7–9 балів
1. **Область видимості `let`:** Демонстрація ізоляції локальної змінної `userName` всередині блоку `if` від однойменної глобальної змінної.
2. **Підтвердження дії:** Запит імені й віку з наступним викликом `confirm()` для розгалуження дій (`Welcome!` / `Goodbye!`).
3. **Парне / Непарне число:** Перевірка числа на парність за допомогою оператора залишку від ділення `%`.

### 🔴 Рівень 10–12 балів
1. **Функція & Block Scope:** Функція `calculate()` з перевіркою роботи змінної `result` на рівні функції та локального блоку `if`.
2. **Гра "Secret Number":** Обчислення секретного числа за формулою `journalNumber % 10` та перевірка здогадки користувача.
3. **Сума чисел:** Отримання двох чисел та виведення їх суми з конкатенацією рядків через оператор `+`.
